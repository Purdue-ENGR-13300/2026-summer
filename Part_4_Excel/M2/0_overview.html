2. MS Excel 2#

This module will use MS Excel as a computational tool to perform engineering calculations and display the results so that others can understand the meaning of the data. We will also cover basic statistical concepts that measure characteristics of a set of data that include central tendency, variation and distributions. We will use MS Excel to perform statistical calculations and display results using histograms. Later in the course, we will revisit the statistics with other computational tools.

Topics Covered

  • Using MS Excel as a computational tool

  • Creating graphs and plots in MS Excel

  • Statistical properties of data - measures of central tendency and variation

  • Distributions of data

  • Modeling linear and nonlinear phenomena

  • Using conditionals in MS Excel

Prerequisite Knowledge for this Module

To be successful in this module, you should already know:

  • How to use MS Excel to perform simple calculations

  • How to create a chart in MS Excel

  • How to work on a team with other students

Learning Objectives and Course Outcomes

At the end of this module, you will be able to:

  • Describe central tendencies of data using statistical properties

  • Describe distributions of data

  • Display data on a histogram using MS Excel

These learning objectives are directly connected to the following Course Outcomes:

CO 1.1:

Visually represent data and derive meaningful information from data.

CO 1.2:

Apply key engineering statistics concepts including mean, median, mode, variance and standard deviation to engineering problems.

CO 2.1:

Contribute to team products and discussions.

CO 3.1:

Communicate engineering concepts, ideas and decisions effectively and professionally in diverse ways such as written, visual and oral.
